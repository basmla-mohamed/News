## 🌐 INFORMATION WITHOUT LIMITS

*Discover the stories. Explore the categories. Find what matters.*

</div>

**News** is a web-based news platform that retrieves news articles from an external API and presents them through an organized, responsive interface.

Built with HTML, Bootstrap, JavaScript, jQuery, and Sass, the project focuses on making news discovery easier through category-based browsing and search functionality.

The goal is simple: turn external news data into a clear and engaging browsing experience.
