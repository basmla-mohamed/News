# News App

A responsive news website that fetches live top headlines from NewsAPI.

## Features
- Browse top headlines
- Filter news by category
- Search for articles by keyword
- Pagination to move between pages
- Responsive design for mobile and desktop

## Built With
- HTML
- CSS
- JavaScript
- jQuery
- Bootstrap
- NewsAPI

## Live Demo
https://github.com/BasmalaMohamed248/News

## How to Run
1. Clone the repository
2. Get a free API key from NewsAPI
3. Add your key in the JavaScript file
4. Open `index.html` in your browser
5. make sure from the current date before using to show news
